Privacy

This is a small portfolio site. It does not ask you for anything.

What this site collects

Nothing. There are no forms, no accounts, no analytics and no tracking cookies. The fonts and images are served from this site.

YouTube

The home page has one YouTube player. It uses YouTube’s privacy mode and does not play by itself. If you press play, YouTube may set cookies and collect data under its own privacy policy.

Hosting

The site is hosted on GitHub Pages. GitHub keeps technical logs of visits, such as IP addresses, to run and protect its service.

Changes

If any of this changes, this page will say so plainly.
